## 当前约束

`AGENTS.md` 与用户最新指令优先。中文按已确认的 UI 组件读取、构建或消费边界生成，原游戏业务数据、菜单索引、选项值和动作保持原样。Mod 拦截最终文字输出并使用自己的字体后端；原生 UI 继续决定位置、居中、换行、行距、选择框、点击区、背景、资源缓存、重绘和淡变。

不建立固定页面坐标表、独立显示计划或 Present 叠字。必要的编码与真实度量是原生接口的扩展，不能让 UTF-8 经逐字节计宽路径，也不能以两字节传输编码假充字体自然宽度。没有测试、断言、游戏运行、注入验证或模拟操作；编译只生成交付物。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| launcher | 定位根目录下 package、核对游戏版本、由用户启动时加载驻留桥 |
| loader | 通用稳定 x86 入口、模块租约、调用、状态交接与发布控制，不识别界面或翻译 |
| adapter | 已确认的原生调用点、组件上下文、参数读取、文字/度量/绘制接入 |
| main_menu | 单次已接入组件的文本请求，涵盖主界面、启动加载与开场诗，保留原生动态值 |
| catalog | 完整 UTF-8 词库与校准字符集 |
| semantic | 组件到词条、原生版本/年份/资源显示参数到中文模板 |
| layout | Unicode 与原生安全传输编码；无页面位置、行槽或控件布局 |
| render | 字体身份、真实度量、高清光栅化，在已确认的原生组件文字绘制调用内即时输出 |

六个业务 DLL 通过 Host 同步调用，不互相导入。共享服务使用定宽字段和借用指针，借用只限当前同步调用；传给原生函数并跨 Before/After 的字节由驻留堆持有。新重建使用 ABI 1，明确不兼容已清理的历史 ABI 3。

## 主界面捕获

| 原生位置 | 组件语义与处理 |
| --- | --- |
| `0x125BDC → 0xCFFB0` | 原主菜单绘制作用域 |
| `0xD0367 → 0x10E5A0` | 按原 EBX 菜单索引读取并翻译标签，不改行记录 |
| `0x12473A → 0x124690`、`0x12474C` | 读取原版本值，在显示格式化边界提供“版本”文本 |
| `0x125137 / 0x12519C / 0x1251E4 → 0x162300` | 出品、版权、作者段落，在原 tokenizer 之前替换，保留 `<br>`、姓名、网站与原年份 |
| 原 `strlen×8`、版本居中和段落宽度计算点 | 消费与绘制相同的真实字体度量 |
| 原完整文字输出调用 | Mod 输出，原生继续控制光标、颜色和后续 UI 流程 |

基本七项与原条件索引 7“额外内容”均在词库中。条件是否成立仍由游戏判断。游戏标题图片与制作组图片继续由原生图像路径处理，不作为文字组件误捕获。选择变化、失焦/恢复和子窗口背景复制需沿其实际原生读取与缓存链覆盖，不能凭首次绘制覆盖宣称全部完成。

## 启动加载捕获

启动标题在 `0x180894 → 0x10E5A0` 的原生文字调用替换文本。音频只在 `0x180B4D / 0x180B59 → 0xB3D0` 内、开场加载只在 `0x180B52 → 0xC1C0` 内选择其已确认进度调用；初始化与设备失败通过各自启动调用点选择。全部七处进度调用继续把原英文交给 `0x123DF0`，中文只借给内部 `0x123E6D → 0x10E5A0` 的显示参数。

进度参数取自已确认的原调用寄存器或局部缓冲，成功资源显示键由词库翻译，失败时实际资源路径保留。借用字节仅在对应原生调用 Before/After 之间存活；原英文缓冲、截断和日志保留。中文复用现有安全编码、真实宽度与完整串即时绘制，直接进入原生主面，原清屏、上传、失败等待和重绘继续消费原生已绘像素。不新增固定行槽、Present 叠字、等待期间的文字重放或驻留 ABI。静态依据及旧文档纠正见 [启动加载记录](evidence/20261019-startup-loading-native.md)。

## 开场诗捕获

两句引言在 `1255EC/1256C2 → 10E5A0` 借入中文，保留原生位置、颜色和描边。`12582F → 124710` 使用既有版本格式化、真实宽度与绘制链。十一句诗在 `1258B5 → 125370` 的原生作用域内，按 EDI 行索引于 `125430` 将 `[EBP-70]` 显示副本替换为中文并返回实际字宽；后续原指令继续计算居中，原循环继续管理行距。`125285/12530E → 10E5A0` 即时绘入原生主面。

该作用域不保存文本或页面布局，不持有业务 DLL 调用帧跨等待。中文像素由原生表面保存，既有逐句灰度、黄色定色、整面淡变、上传、等待和跳过流程继续执行。没有新增 Present、淡变或输入 Hook；共享结构、Host ABI 和驻留 DLL 均不变。静态证据、旧文档违规纠正及交付状态见 [开场诗记录](evidence/20261019-intro-poem-native.md)。

## 编码与字体

原 `0x10E5A0` 会重映射 `C4/E4/F6` 字节。非 ASCII 字符以两字节原生安全 token 传入原解析器，token 表按值跨代保存；ASCII 与控制标记不变。绘制及宽度服务把 token 解码成 Unicode，调用同一字号、同一像素密度的字体度量。传输字节数不用于中文宽度。

字体仍为系统 `msyhbd.ttc`、face 0、常规样式与 normal hinting，由游戏目录的 SDL2_ttf 及同一 SDL2 实例提供 Blended 光栅化。固定参考字符、当前已提交词库字符、标点共同校准。选满足字面预算和稳定包络的最大统一字号，不按某条中文临时缩字。字面预算 9（说明角色 8）是逻辑像素预算，不等于名义点数。

原生 UI 在当次文字绘制调用中提供目标、位置、颜色、裁剪与顺序。Mod 依据已确认的原生目标像素密度生成本次完整文字的高清字形，直接提交到该目标；已经绘入的像素随后由游戏自己的 surface/texture 复制、覆盖、上传、销毁及重绘流程管理。

禁止扫描或比较全局表面像素，禁止为通用像素写入维护文字覆盖关系，禁止保存像素和 UTF-8、位置、裁剪、样式的贡献序列。原生 RenderCopy 只复制原生已有内容，不触发 Mod 遍历旧文字、重物化完整源或替换整幅画面。原生 Present 不用于补画文字。字体、字形自身的度量与光栅缓存不含 UI 位置和页面内容。

主菜单原生逻辑域为 800×600。高清改造扩展既有主面、上传纹理与背景资源的实际物理尺寸，在组件文字调用中即时绘入原尺寸字形；图像和原生绘制按已确认坐标域转换，原生逻辑矩形不改成物理矩形。具体 owner、直接读写、保存恢复、淡变及尺寸事件依据见 [静态边界记录](evidence/20261019-native-hd-target-boundaries.md)。位置、布局、缓存生命周期和输入映射仍由游戏管理。详细字体质量要求见 [字体规范](font-rendering.md)。

## 全局语言切换

2026-11-10 的共用擦除原因是旧 Scene 先重画背景，再遍历不完整的组件集合。当前源码已删除整页组件绘制、缓存物化和缓存矩形替换；相关历史源容器描述不能作为实现授权。整改过程及旧交付回执见 [共用语言重建整改](evidence/20261110-common-language-reconstruction.md) 与 [第4、5代记录](evidence/20261110-native-full-language-boundaries.md)。

语言选择通过原生普通输入 `D1CD4` 和动画输入 `D26AB` 识别，只提交语言版本和原生构建请求。共同菜单、普通等待及动画等待边界驱动完整的原生显示构造；原控件、选择、命中、光标、上传和呈现继续消费同一构造结果。每个构造区间的业务、随机数、文件动作、新输入和淡变边界由静态证据分离，不能把整函数重入当成纯绘制。

first、second、menu 及四个 named 缓存的语言 revision 跟随原 save/restore/free。过期父缓存必须用它自己的真实场景底和完整语义 owner 重建后，调用原 save 更新；不能仅刷新前景菜单，或拿尚未还原的地图、弹窗前景作为父背景。原生缓存只持有像素，Mod 不扫描像素、不替换矩形、不存储页面字段、位置或文字重放序列。

## 构建与发布

所有构建请求进入根 `build.ps1` / `build-queue.ps1`。批次开始冻结请求集合，兼容的后续请求合并为下一批；模块取并集，任一全图请求即全图。统一工具链与发布参数，批次只配置和增量构建各一次。源码提交后保持冻结至回执完成。

正式入口为根 `uwcn_launcher.exe`，驻留 DLL 为 `package/uwcn_loader.dll`，业务 DLL 位于 `package/modules/`，数据和适配文件也在 package。被替换文件先按原相对路径移入根 `回收/` 的事务目录，再放新文件。不生成平行运行包。

兼容模块事务是 Prepare、ReadyToPublish、文件归档替换、Commit、Applied；Ready 与构建成功均不能冒充 Applied。通用驻留桥自身或 ABI 迁移不宣称热更。源码、编译、正式发布和运行时应用分别记录。当前待办及真实完成范围以 README 和本轮交付记录为准，历史证据中的旧完成状态不继承。
