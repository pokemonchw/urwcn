# 原生区域缓存的中性源组件

本记录只来自原始 `urw.exe` 的静态反汇编及源码审读。没有启动游戏、注入、运行产物或测试。

## 原生边界

`10C540` 接收 ECX 缓存名、EDX 原生 `SDL_Rect*`，创建并转换一个 799×600 的原生缓存表面。`10C66E` 的原生 SDL 复制始终以两个空矩形复制完整主表面；返回地址为 `10C674`。之后 `10C67A` 把调用者提供的恢复矩形指针写入 `A1C1CA0[index]`。矩形不是保存图像的范围。

`10C690` 按原生名字查找同一缓存槽。`10C6EF` 调用原导入 `18C200 = SDL_SetSurfaceBlendMode(cache, 0)`，再把 `A1C1CA0[index]` 同时作为原生源、目标矩形，复制该缓存到 `61BBB10`；返回地址为 `10C711`。这里的矩形是完整缓存组件的复制输入，不携带别的控件所有权。

`10DBB0` 接收 ECX=x、EDX=y、栈上 w/h，构造本地矩形，在 `10DBE9` 前从原生 `A1C1CE0` 菜单缓存恢复该区域。全 `.text` 直接调用只有 `D1207`、`D1522`；两个调用都直接读取真实菜单头 `5F54A20/+4/+8/+C`，并非从选中行的旧命中矩形取值。两处都位于原生 `D1120` 选择生命周期。

已有 40 个确证的原生缓存复制返回地址仍由 `native_ui_cache_owners.cpp` 的静态 census 限定。没有扩大为通用 SDL 图像内容观察。

## 现在的源协议

`native_ui_cache_owners::RestoreInput` 同步借用原生表面、源矩形和目标矩形。原生复制之前，Scene 创建一个不可变的 `CacheRegion` 版本，绑定实际缓存槽资源生命周期、缓存的冻结 `SceneRevision`、实际原生表面构造参数及该缓存复制的输入。`PreparedRestore` 从此同一源生成原生参数；正在执行的原生复制直接消费这些参数，保留对原调用者目标矩形的 SDL 写回语义。成功以后才把同一组件加入当前源层。

同一槽、同一资源生命周期的恢复替换该组件并更新原生层位，不在每次选择更新后新增显示节点。菜单区域使用显式保留的真实 Menu InputOwner，重新读取上述四个原生字段；其它区域使用原完整缓存接口提供的矩形输入。没有坐标表，没有按几何重叠给其它控件分组，没有文字绘制记录。

语言切换时，组件以实际原生构造输入创建临时缓存资源，临时安装到真实原生 owner 槽，把冻结的中性 Scene 用完整原生组件物化到该资源，再通过相同的原生缓存复制操作提交该缓存自己的矩形。结束恢复调用者的 owner/目标并释放临时资源。没有使用旧语言纹理或像素作为背景，没有常驻的平行 Mod 图像缓存。

同一段 Scene 物化内部，renderer 目标和 headingicons 复制资源保持借出到全部后续 Menu/Flow 原生消费者结束，随后才按相反顺序恢复原 owner/alias 并释放新资源。不能在单个 renderer 节点返回时过早恢复旧语言 target，让后面的原生消费者读回旧纹理。

Scene 的可达性遍历除了缓存绑定和父源层，还包含每个区域组件的 `source` 依赖。对被区域源引用的活动 revision 进行修改时同样 COW。新的区域版本始终指向复制开始前已冻结的 revision；它不会把旧版本重新绑定到新源，因此同槽缓存的旧区域依赖保持为单向版本链，不能形成指向自身的循环。

## 状态及边界

Scene 状态保存语言 generation、每槽已物化 generation、缓存生命周期、中性原生构造输入、不可变区域版本和源 revision 引用。`native_targets` 的 NGT2 保存实际资源身份、密度和中性表面构造参数，不保存像素或文字。

NGT1/HDA4 的已发布旧状态没有这些原生组件源。NGT2 不把旧位图反推为源，因此本修改不提供从该旧状态原位补造全局源的迁移。Scene revision 0 表示原生 root 尚未构造；语言重绘或缓存准备返回 `Status::unavailable`，不会绘制伪造 root。

区域源协议不补齐尚未建模的业务显示源。消息流、地图/肖像等源的静态确认与完整组件接线仍须分别完成，才能宣称所有界面均能立即重建。
