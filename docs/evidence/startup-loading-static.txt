18084B calls 112980 with ECX=string RVA1DC88C (image resource).

x=10, y=10, original text, mapped white, outline=0 with the documented text ABI.

Implementation timing
The launcher creates a new process with a temporary debug startup boundary.
After Windows resolves imports, a PE-entry breakpoint suspends the primary
thread; the launcher restores that byte and EIP and detaches the debugger.
It then loads and explicitly initializes the resident module, and resumes
the primary thread. This places the fixed startup patches before game entry.
This is the existing launcher timing, not an instruction to launch or inject
the game during implementation. Current source, build and publication status
are recorded separately in 20261019-startup-loading-native.md. No runtime
startup result is claimed.
