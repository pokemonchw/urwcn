# 百科关键词编辑中的完整原生语言重建

对象为 Windows 3.89.1。只读原 PE 和源码，没有启动游戏、运行产物或测试。原 `3E589→10F5B0` 返回为 `3E58E`；getst 内的真实非按键返回边界与姓名共用 `10F71E`，通过这个确切原 caller 区分输入 owner。

语言请求到达该输入时，完整构造当前原主题 `2EA820` 的百科页面，按原动作/英文链接标识恢复原菜单选择。新 `3E680` 在 `3E697→3E6D1` 跳过历史清除和音乐；新 D1120 平衡退出，`3E4CF→3E3F2` 和 `3E820→3E942` 在原尾部返回，不进入新关键词输入或改写真实 getst 输入缓冲。

随后运行原 `3E4F0..3E582` 关键词 prompt 构造区间。它完整执行 `11480` 面板、`10E5A0` 空栏及原颜色/光标初始参数；没有包围帧局部读取。原 EBX 来自 `3E2F5` 对实际 `SDL_MapRGB` IAT (`18C1F8`) 的载入，专用同步 ABI 桥传入同一函数指针并保存四个非易失寄存器。三段参数清理分别在原区间内完成；`3E57F ADD ESP,10h` 后到 `3E582 MOV EDX,1Eh` 的新 inline Hook `516B` 返回同步桥，不执行 `3E589`，因此不清除、重开或结束真正的 getst。

完整百科构造使用原 flip=1，而它的纯构造尾部不执行普通呈现。关键词分支保存并恢复实际输入的原 flip，使真实 getst 仍按自己的 `10F6CE` 判断执行上传和呈现；不在 Mod 中另行 Present。原 getst 的 ESI、EDI、EBX 分别从 `[EBP-A4h]`、`[EBP-B8h]`、`[EBP-ACh]` 恢复，再从 `10F6A0` 继续完整文字和光标构造。原 `A49B9A8` 缓冲、字节容量和输入循环不变，完成后仍由原调用者执行关键词查找、历史和主题动作。

本边界不依赖普通百科 D1120 的输入 scope，因此关键词尚在编辑时即可消费语言请求，不再等待用户结束编辑。
