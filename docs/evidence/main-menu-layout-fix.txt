Final renderer composition
D1225 ->10AF90 uploads and copies the native software frame; D124A ->10B3C0
then processes additional drawing records. The native renderer branch also
converges at D1292: PUSH [VA A6110CC], the renderer (RVA A2110CC).
Both base-frame copies use SDL_RenderCopy(renderer,texture,NULL,NULL).
The corrected call roles and mapping evidence are in font-rendering-static.txt.
D1298 has complete bytes FF D6 83 C4 04, CALL ESI followed by ADD ESP,4.
ESI is the original SDL_RenderPresent pointer. Replace the whole five-byte
span with CALL to the resident stdcall present bridge; its RET4 preserves the
removed caller cleanup. D129D is XOR EAX,EAX, so prior ADD flags are not consumed.
The bridge composes text only inside the main-menu input scope, then invokes
the original SDL_RenderPresent. Other interfaces keep the original presentation.

The core retains only its own UTF-8 semantic lines and logical row bounds.
It suppresses the old menu/footer/version glyphs before their software draw.
At final presentation, it rasterizes the installed Microsoft YaHei at the actual

SDL_RenderSetScale in SDL 2.30 changes only scale, keeping the physical viewport
and clip intact. The bridge saves scale, selects scale1 to read the physical
viewport/clip, temporarily disables clip, renders pixel-aligned glyph textures,
restores clip while scale is still1, then restores scale. It never changes render
target, viewport, logical size or mouse event conversion.
