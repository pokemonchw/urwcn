## 原生按钮

`124C3E → 114680` 借用完整编码的 ` 按任意键继续 `。借用存储来自 Host 堆，仅存活于该次原生调用，After 释放。按钮不包含原控件的 `< >` 高亮标记或点号键帽标记。

`native_button.h` 接入原控件三个边界：

- `1146DD`：实际整串字宽换算为原八单位瓦片数量（向上取整），原生循环继续绘制左右端盖及中间背景。
- `1148E9 → sprintf("%c")` After：把原单字节临时缓冲补为完整的一字节 ASCII 或双字节中文传输字符。绘制仍经 `114956 → 10E5A0`。
- `11498A`：原 `ADD ESI,8` 已执行，以完整前缀的两次同源字宽差补偿推进；同时保留原 EDX 指针加载并按完整字符推进 EBX。原循环及结尾 `ESI+4` 光标更新继续运行。

推进内联补丁从 `11498A` 开始，保留其原跳转入口。不得把补丁从 `114987` 跨越到该入口，否则其他含标记按钮可能跳入补丁中间。原 `1AAE20` 字节为 `3C 3E 00`（`<>`），空格执行正常字形与推进分支。以上扩展仅在该次 About 按钮调用作用域内生效。

## 绘制、缓存与热发布边界

文字沿当前 `10E5A0` 完整文本 → 原描边/前景调用 → Mod 即时光栅流程，按原生主面实际物理尺寸绘入 `61BBB10`。游戏继续管理控件位置、面板、光标、选择、输入、缓存、上传及呈现。没有新 SDL Present 叠层、全局像素跟踪或文字记录重放；字体缓存不保存 UI 坐标。

新 About scope 从原 `125E39` 调用到其返回，由驻留桥 token 管理；没有业务 DLL 栈帧跨越输入等待。依赖更新和窗口资源重建时，已知 About scope 可同步调用完整 `1247C0` 重建原生面板；只在该次同步重绘中跳过 `124C46 → D3C80`，然后执行原 epilogue 与 `10B720` 上传呈现。不能用 `native_fragment(1247C0,124C4B)`，因为那会在局部栈未平衡时返回。

已发布前代没有 About scope，故对更新前就打开的窗口，仅在原 `D3D05 → D3BF0` 边界检查 `D3C80` 的原返回地址是否为 `124C4B`，确认后请求一次原生重绘。若原窗口正处于驻留 `SDL_WaitEvent` 等待，需要真实事件令原循环返回后才到此边界；不能把 Applied 回执说成旧窗口已立即换字，也不发送模拟输入或要求退出重启。没有使用不能静态证明完整性的栈回溯扫描。

About 接入本身不改变 Host ABI、Active 保存布局或其他业务模块的状态格式。工作区同时有独立的设置页、语言切换修改，本记录只说明 About 部分。正式发布沿用项目自动热发布事务和统一队列。
