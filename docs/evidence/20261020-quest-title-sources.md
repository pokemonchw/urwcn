## 旧 type 35 记录的原生动物域

4AD4F0 的一般 EDX=0 调用可以进入专名分支，但 type35 的正常目标选择有更窄的来源约束：542D30 排除非人类中 state=9 或 owner=-1 的玩家所有对象，543340 的玩家命名动作只对这些玩家所有对象调用5431D0。5350D0购买设owner=-1，566F40释放只改state而保留owner，40D800加载也保留玩家所有权；没有正常出售路径把已命名动物重新加入村落候选。

普通对话546200通过4AADD0限制category=1；特殊topic0任务回访4219BD所需AI0x46仅由人类dispatcher56AF9E→4275E0写入。默认动物的+30专名和+1DC known由4CE8E0清零，动物构造器不设置它们。因此按当前3.89正常生成语义，旧type35标题的subject属于NPC动物称呼域。源码按原生固定后缀` in the forest cover`的20字节长度取出subject，构造`format.005c9460`及精确npc源，不执行目标查找、不改旧记录。

隐藏调试命令`-`、`j`、`0`可通过57A8C0/57A904编辑动物owner；这是单独的调试编辑器，并非普通命名或交易流程。完整分支地址、初始化和所有权证据见`20261020-type35-animal-name-domain.md`。本结论范围是当前3.89本体；未推断其他历史版本的记录生成语义。

进一步反编译了 `541900`、`40CB20` 和 `40CC70`。`541900` 通过地图对象及 `615192C` 的 unique id 处理任务回访，但也会移动对象、改写状态，不能为了翻译重放。`40CB20` 可在当前对象池或 `.CRS` 文件中读取完整 `568` 字节对象；`40CC70` 则汇总持久化对象的五个状态计数。它们提供的是所读对象的状态，尚无证据证明其专名/熟识/幼体标识与旧标题生成时一致。原生未找到对象时的零记录也不是标题来源，因此本次没有把这些路径当作旧标题的推测性判别规则。

成功 `fread` 会替换原生缓冲的记录身份，接入点同时清除该标题地址的上一份源绑定，再按已证类型构造新来源。不能因为新旧记录恰巧英文同名，就继承上一条任务的来源。

整记录复制前的type35若已有同一标题owner且完整英文完全一致的真实构造图，则保留该图；这与首次文件读取后的语法恢复是两个原生生命周期。因而隐藏调试编辑器生成的新专名仍保留已捕获identity，复制不会把它改成词典词。

## 巨型调度器中的格式串

`settlement-dispatch-final-classification.tsv` 记录最后 32 个候选的实际消费者：22 个进入共用消息，10 个属于文件路径、导出文件、查询控制串或未消费的局部诊断缓冲。这项分类根据逐指令数据流完成，未把同一函数中的其他消息调用当作消费者。

另从完整静态反汇编重新建立 `settlement-message-call-ledger.tsv`，逐条收录 1,402 个真实 `CALL 4F6510`，并关联既有参数来源。由此发现旧反编译清单遗漏的 `5289DB`：`52899E` 将伤口内部效果码用于 `Haavatulos: %s`，`5289CE` 添加 debug 前缀后显示。该表是全调用来源账，包含缓冲表达式及参数来源；不能把有一行记录等同于已完成每个动态分支的翻译。

本文件记录源码及翻译来源。最终编译和正式发布回执见 `20261020-shared-message-delivery.md`，没有运行游戏或测试。
