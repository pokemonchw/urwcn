## 原生语义与显示生命周期

`561B00` 先展开 KEY，`560CB0` 选择正文与 HEAR 分支，`561330 → 5601C0` 展开真实标签值，再执行 `[]` 子查询及该次实际发生的 HEAR `%s` 替换。Mod 观察同一次选择与返回值；不再运行一次构建函数，不修改条件键、对象数据、原英文缓冲或声音键。标签位于 `[]` 或 `{}` 内时保留原值。`561480` 的七槽对话选择仍由游戏执行。缺文件、未命中 KEY、debug selector 等结果按原生实际分支区分，不能用翻译未命中作为来源判断。

物品名称调用链 `5601C0 → 451770 → 4AE750 → 4AECB0 → 561B00` 可复入消息构造。未完成的语义帧按原生入口/出口压栈、弹栈；不能用单个临时消息覆盖外层。已构造中文仅与真实生产者缓冲及英文值身份关联，不携带屏幕位置、行槽、裁剪、样式或像素，不作为绘制重放表。

`F6510` 内仍用英文执行 `{}` 声音字段提取、大小写处理、与 `005E6AC0` 的重复比较。只有 `004F6A45..004F6D8A` 的原生显示区间借入中文；退出该区间恢复原文，后续显式音效及英文关键词音效路径保持。消息日志调用 `004F6EB3 → 004F6280` 使用按原生控制字符规则形成的英文正文，未把中文传输 token 写入 `msglog.txt`。
