## 共同输入与原生缓存

`D1120` 原 CALL 保留。`D12B4` 收到真实 `-2` 后，将当前原生菜单选择传给同步构建回调；完成后恢复原生全局选择、`[EBP-430h]`、重绘局部 `[EBP-41Ch]` 和 EBX，续接 `D1167`。该原函数的 `D1189` 保存完整新页面，后续选择框、鼠标和呈现继续使用这一原生缓存。

D1120 的保存槽由原始 `SUB ESP,434h` 和 PUSH 顺序确定：EBX 为 `[EBP-438h]`、ESI 为 `[EBP-43Ch]`、EDI 为 `[EBP-440h]`。它们是正在暂停的真实调用帧，不是 Mod 缓存字段。

`native_ui_scene::saved_menu` 仅取真实首背景缓存已持有的 CF790/CF990 菜单模型，供原生主菜单构建使用。它不遍历绘制其它子项，也不恢复旧 Scene 绘制能力。适用调用限定为原主菜单打开的关于、鸣谢、创建方式和读档窗口；这些原调用先保存的首背景确实包含主菜单。同步激活该菜单、重建完整主菜单并执行原 `10DA10` 保存后，恢复当前窗口自己的真实菜单实例。没有改写缓存矩形、扫描像素或重放文字贡献。旧 HDA7 来源图仍属待退役架构，借用其中真实菜单输入不代表整个来源图合规。
