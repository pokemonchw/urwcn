# Windows 季节、属性与百科同步的静态接入

本轮根据用户“Linux 上的进度需要全部同步到 Windows”同步已有语义和词库。本文负责季节与肖像、属性确认、百科、文化简介和地图图例，不将 Linux 的 ELF RVA 或 ABI 用于 Windows。

目标为 Windows x86《不真实的世界》3.89 / Steam Build 25939378。原 PE SHA-256 为 `e0b15bbbe16ffcd95d4ab61f08fe95dea4b95ebe1b3de428dae1d9477a9710d9`，首选基址 `0x400000`。本机 `GAME.NFO` SHA-256 为 `071f384ad992d0a688833693f207a5cf8a969b4811e5e6603597d189087a4d5d`，与 Linux 译文来源完全相同，原生二进制读取偏移的词库键可以共用。

仅运行 objdump、文件哈希与 Ghidra 的只读 `-process urw.exe -readOnly -noanalysis` 反编译。Ghidra 使用既有 `build/load-saved-ghidra/uwcn-load-saved.gpr` 和独立 settings/cache；提取脚本为 `windows_sync_extract.java`。本地完整指令和反编译位于 `build/windows-sync-pe.asm`、`build/windows-sync-profile-encyclopedia.c`，不纳入源码仓库。不启动游戏、不注入、不模拟输入、不运行产物或测试、不创建测试或断言。

## 季节、肖像和属性

实现位于 `modules/adapter/windows_profile_extras.inc`。季节 `FA40` 的 `FB36 → CFFB0` 建立同步绘制作用域；共享 `D01A5` 标题和 `D031F` 按键标签按原动作 1–4、ESC 借入中文，不改列表中的原英文或月份 4/6/8/11。`FA4D → 162300` 与 `125F0 → 162300` 分别是季节难度说明、肖像选择提示，随后原 `F210` 段落消费完整词元。

自然输入返回 `D12B4` 的原调用者 `FB40` 仅重跑完整 `FB36 → CFFB0` 调用，随后原生保存菜单背景、高亮原选择、呈现。没有重入含文件和季节业务的 `FA40`。

属性原函数 `E66B0` 的接入包括：

- `E670E/E6730/E6900/E6953 → 116270`：身体素质、体格、心智与外貌四个分组。
- `E6828..E6931 → E10F0`：十一项属性的显示标签；`E1110 → 10E5A0` 绘字，原属性值、柱条和其他业务继续执行。
- `E6784 → F9030`：原生已经拼接的姓名与民族。文化编号来自 `Plr+0xD` 的 RVA `A32A6F5`，姓名保留，民族复用十种文化译名。姓名仅在显示边界转换，内部民族原文与存档不变。
- `E67AF → 10D0`：仅非零 mode 的开局年龄显示；保留原年龄。`E67F6` 的原生居中改用相同字形度量。
- `E6995/E6A45` 和 `E6A2A/E6AD2 → 10E5A0`：身高体重标签、原数值与已经选定的单位后缀。
- `E6B58/E6B64/E6BEA/E6BF6 → 162300`：属性完成提示、继续提示、背景确认与满意度说明。`E6B97/E6C28 → 10EB40` 使用原生段落。
- `E6CA1 → CFFB0`：Y/N 标签只翻译动作后缀，原默认选择、REROLL 与角色流程不变。

通用软件标题 `1157B0` 的两处 `115849/1159C9` 原 `strlen*8` 已接完整字形度量，`115A94` 仍在原文字调用内即时绘制。姓名标题 `F909D/F90B5` 同样处理中文，但只覆盖 `E6784 → F9030` 的属性标题。先前本文声称该组件也被游戏内 HUD 共用，这一判断有误，导致 HUD 民族显示漏接；HUD 的独立调用为 `FA493/FA4D8/FA507`，补接依据见 [游戏内角色面板民族漏译](20261019-hud-culture-identity.md)。标题、按钮和段落没有 Mod 坐标、行槽或独立排版。

属性确认、肖像阶段已完成面板的完整纯重绘边界仍未确认；与 Linux 当前行为一致，旧像素沿游戏后续原生构建更新，没有重入角色随机生成或输入等待来冒充刷新。

## 完整百科与文化简介

实现位于 `modules/adapter/windows_encyclopedia.inc`。共用现有 312 个不同主题、608 段完整译文与 447 个链接名称，正式文件仍为 `catalog/zh-CN/cultures.tsv`；没有逐词拼装正文。

- `3DD10` 为 `show_topic`。`3DF9C/3DFBE/3E021 → D4280` 返回后，通过游戏自己的 UCRT `fgetpos` 导入 `18C4DC` 读取二进制文件偏移，避开 Mod 与原生 CRT 的 FILE 结构差异。`3E054 → 3D820` 是完整原生正文借入边界。
- `3D820` 是 `link_show`；其 200 字节源副本按完整传输字符、完整主题名和控制标记拆为每次至多 180 字节的同步参数。游戏自己的光标、词表、换行和段落连续执行。
- `3D93A → 162300` 将完整双字节中文转换为可换行词元；`3D8E7` 保留原字节长度，并让随后的原生 JAE 将两字节汉字视为正文。`3D9BC/3DAC7` 两处原生换行比较消费真实显示宽度。`3DC13/3DC2C` 只取消中文词元分隔语法造成的可见西文空格。
- `3D300` 为 `Lisaa_Linkit`，原英文主题表、当前主题表与历史不改写。`3D39A/3D470/3D52A` 的匹配完整作者标注的英文主题身份，避免 SPEAR 成为 KAUMOLAIS.SPEAR 内第二链接；`3D4BD/3D4EB` 将完整中文视为主题边界。`3D353/3D87B` 在原生大写之后恢复完整传输字符，原拉丁词形仍保留原生转换。
- `3D591/3D5FB/3D6AE` 同步扩展测量、前缀光标与原生鼠标区域宽度；`3D728` 下划线消费同一实际宽度，`3D78D/3DBA1` 在原调用内借入同一完整显示标签。原生英文查找键、原生字节复制长度与链接动作保持。
- `3DF31/3E75A` 接主题标题和百科总标题；`3E148/3E1A3/3E1BF/3E1D6` 接 HOME、后退、ESC、关键词导航，保留键帽与原返回动作。`3E317..3E383` 接首次入场的十段说明；`3E441 → 162530` 下的 `162627` 接三条帮助，未扩大到其他帮助文件读取。
- `3DCE9/3DCFE/3E8AF/3E8C4` 是原生未找到主题的提示及继续按钮。
- `F7BA/E0ECA → 3CA90` 限定文化选择与技能页的原生简介，分别在 `3CBA8/3CC8A` 的原英文摘要截断之后借入标题和完整短摘要；`3CCF3` 的 F1 标签保持原命中与动作。没有扩大到缺少已确认摘要的其他 Hotspot 调用。

历史版本曾通过 `3E680` 浏览器重入刷新百科；该专页重入方案已从 2026-10-20 的本轮源码删除。当前源码由共同 LinkFlow 的中性记录调用完整 `3D820`，与原 Menu/InputOwner、公共源容器及缓存协议一同重建，不再使用上述页面跳转链。具体新接口、英文链接身份、选择与状态保存见 [原生链接流记录](20261019-native-link-flow.md)。本段只说明源码替换，不表示本轮已经编译或正式发布。

## 文化地图图例与边界

旧软件图例 `E11B0` 和现代图例构建器 `E3A50` 的标题、十一种文化共 24 处显示调用都已接入；现代图例文字直接进入原 `10E260` renderer 路径，旧图例进入原 `10E5A0` 软件路径。现代标题调用 `E3A9A → 1166C0` 的标题为第四个栈参数，原 flags=0x28 的左对齐分支保留。

现代图例的原生 200×160 表面来自 `E3A69`（返回 `E3A6F`），软件 renderer 来自 `E3A72`；上传后由游戏持有 CultureDialogTexture。主地图目标来自 `E3DCC`（返回 `E3DD2`）。这些目标的密度、原生 QueryTexture 逻辑尺寸和 SetRenderTarget 接入由本轮 `native_targets.cpp` 同步处理；没有在 Present/Copy 时重放文字。地图图例沿原地图重建生命周期更新。
