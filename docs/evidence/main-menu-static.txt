Confirmed business path
-----------------------

The seven visible full-version fields are index 0 LOAD SAVED CHARACTER, 1 CREATE A CHARACTER, 2 SETUP, 3 ANCESTORS, 4 ABOUT, 5 CREDITS, 6 QUIT. These indices dispatch directly through the jump table at 0x125ED4. An eighth conditional BONUS MATERIAL entry exists in the original program; it is outside the supplied screenshot and this implementation scope.
0xCF990 takes ECX=action key and EDX=label; main-menu calls pass key 0. It copies the label and increments the global row count. Original labels remain in their original rows so native actions, input and geometry continue to use the original business data.

Immediate idle reload without synthetic menu input
--------------------------------------------------
Outer menu loop starts at 0x125B80. It draws footer through 0x125BA3 -> 0x1250E0, draws the main panel, draws version through 0x125BD7, draws rows through 0x125BDC, and enters input through 0x125BE1 -> 0xD1120. The footer routine is not a full background redraw; the outer sequence naturally replaces the footer, panel, version, and menu labels.
0xD1120 contains its own idle input loop (0xD14E6 branches back to 0xD11CC). Therefore 0x125BA3 is not reached on each idle input tick. Resident CALL 0xD12A5 -> 0xD0FC0 is an available per-input-loop poll boundary; enable it only in the resident main-menu input scope. No reloadable-core call frame should stay on the stack across the native 0xD1120 invocation.
When reload is requested, the resident tick bridge can return to the already-existing native continuation 0xD19B3 after ending any core lease. That native block writes menu_input_active RVA 0x5F54DF0=0, sets EAX=-1, pops EDI/ESI/EBX, checks the cookie and returns normally from 0xD1120. Its entry bytes are C7 05 F0 4D 35 06 00 00 00 00 83 C8 FF 5F 5E 5B. It does not change selected index RVA 0x5F54AB0 or input mode RVA 0x5F54AB4.
The outer caller at 0x125BFF compares EAX with 7 and at 0x125C02 uses unsigned JA to 0x125B80. Thus -1 reaches the normal outer redraw sequence and the resident 0x125BA3 boundary can perform queued data/core replacement with no old core frame. Do not use 0xD19A9: that preceding block additionally sets input mode=2, which changes the next input setup.
This continuation choice and redraw chain are statically evidenced, not runtime-tested.
