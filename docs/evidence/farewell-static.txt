Confirmed page and lifetime
---------------------------
The supplied screenshot is the exit farewell page, distinct from the seven-row
main menu and startup loading page. The user explicitly added this page to the
translation scope. Its page function is E6E90; its unique direct caller is:

180DF5  cmp dword ptr [VA A6D0BC4],1
180DFC  jne 1809D0
180E02  E8 89 60 F6 FF  call E6E90

E6E90 has no register or stack input contract: it initializes the registers it
uses and reads only its own local stack storage. It starts music_birth.ogg at
E6EA9 -> C000, draws the background at E6EC3 -> 1127C0, then constructs the page.
E6EEC -> 116270 draws its outer frame and title. After drawing the text and the
native Press a key button, the function presents, waits for input, and follows
the original shutdown calls. E71EF calls E6D20 with the empty original string;
that routine ends in original cleanup and exit. A resident page scope can wrap
180E02 -> E6E90 and stay active throughout the native wait. No reloadable module
call frame is needed around the wait, and no menu action or exit action changes.

Present and wait-for-key boundaries
----------------------------------
The page's first native frame submission is:

E718A  E8 01 3E 02 00        call 10AF90

E71BD  FF 35 CC 10 61 0A     push [VA A6110CC] ; renderer
E71C3  FF 15 7C C2 58 00     call [VA 58C27C] ; SDL_RenderPresent

E71CC  E8 AF CA FE FF        call D3C80

D3C80 is the original wait-for-key routine. Before its input loop it uploads
and submits the frame again, so this second present is also an actual required
composition boundary for the farewell page:

D3C9A  E8 F1 72 03 00        call 10AF90
D3CBF  E8 FC 76 03 00        call 10B3C0
D3CCD  FF 35 CC 10 61 0A     push [VA A6110CC]
D3CD3  FF 15 7C C2 58 00     call [VA 58C27C]
D3CD9  83 C4 04              add esp,4

After its original SDL event draining calls, D3D05 -> D3BF0 -> D1C00 is repeated
until a positive input code is returned. This is the same SDL event consumer
used by the main-menu input path. Thus native window-event repaints can reach
the already confirmed D1E70, D1F48 and 10B763 presentation sites while the
farewell page waits. Their existing resident bridges can compose when the
explicit farewell scope is active. Other pages using those shared sites stay
original. This conclusion is static; no focus/input operation was performed.

The six-byte IAT presents at E71C3 and D3CD3 can use a resident cdecl(renderer)
call plus one NOP while retaining the ADD ESP,4. Alternatively, replacing all
nine bytes with CALL rel32 plus four NOPs requires stdcall(renderer) RET4, as
documented for the startup present. The relocated expected IAT operand is the
actual image base +18C27C, not a fixed preferred-base VA.
