译文短语间的空格供原生 tokenizer 分词。编码由现有 Layout 转换成单字节 ASCII / 双字节非ASCII传输字符，避开原 wrapper 改写的 C4/E4/F6。原词元槽为 `0x82` 字节（最大129个有效字节）。静态字符计数得到：含 NUL 标题15字节、按钮42字节、四条说明最长83字节、十三条故事输入最长72字节；这些完整记录已小于词元容量，分词后的短语更短。故事 `sprintf` 仍使用原 `0x400` 缓冲，两个段首另由原生格式添加4字节 `<br>`。原 `10EE68`、`10EF57`、`10EF87` 和 `10E700` 使用同源真实字体度量，不将 UTF-8 裸送入 ASCII 计宽路径。

原生 UI 继续拥有背景、插图、排版、按钮瓦片、输入、缓存及上传呈现。Mod 在原组件文字调用中按真实目标密度即时绘入字形，没有新增坐标表、显示行槽、DisplayPlan、像素跟踪或文字贡献重放。标题翻译发生在原英文标题完成插图识别之后，图片选择不受影响。

## 当前页刷新与语言切换

`FB7D0` 前段包含场景业务，不能直接作为纯重绘函数重跑。本轮只在同步刷新期间：

3. 原尾跳进入 `D3C80`，执行其原生呈现链与栈/安全cookie建立；在 `D3CDC` 继续到 `D3D0F`，保留原 cookie 检查、寄存器恢复和退出，跳过 PollEvent、PumpEvents、FlushEvents 与输入等待。

既有 `D3D05` Hook 通过 `D3C80` 的原调用返回 `17E86A` 识别此页。原 `17E865` 保持未 Hook，因此也能识别更新前已打开的窗口。依赖更新、原生目标重建或 `Shift+F10` 设定刷新请求；原生流程自然到达此边界时重建。若当前线程仍阻塞在原生事件等待，不模拟输入唤醒，不将模块 Applied 回执当作当前页面已可见刷新的证明。
