## 菜单附件名称的来源

4501A0 从传入物品的 +88 附件索引取 descriptor，经 451770(count=1, flags=4) 取得卸下菜单名称。455060 只有钓竿 ID F9 和弓 ID 78 且附件非零时调用它；49FB40 仅判断周围水域，不提供名称或额外类型限制。

- `CONSTANT.OBJ` 的 AC 字节记录：index221 钓竿 +88=227（iron fishhook）；index295..301 的弓 +88=245（Bowstring）。
- 565D00 接鱼钩，把玩家库存索引写钓竿 +88；唯一调用 567642 前 567638 明确要求物品 ID FA。
- 565F20 上弓弦，把玩家库存索引写弓 +88；唯一调用 56762E 前 567627 明确要求物品 ID 79。
- 原始库存 ID FA 为 wooden / bone / iron fishhook，ID79 为 Bowstring。普通附件名称不会进入植物、食物斜线名称的单复数改写分支；新制作名称仍由已证 crafted grammar 处理。
