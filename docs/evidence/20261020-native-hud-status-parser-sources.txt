F9910 complete native summary

Five direct callers: 58C77, 89804, FA744, 1035CC, 1845F6. ECX is mode,
zero stack arguments. Mode 0 builds the complete UI; mode 1 updates it.
The locale consumer uses complete mode 0 from the same accepted source;
ordinary calls retain their original mode. The complete function owns its
native panels, captions, colored bars, ranges, selected status words and
internal string scratch. It does not enter input, RNG or game simulation.

CFAF0 direct Menu-record commit

Complete CFAF0 bypasses CF990. CFBD4 writes the original action, CFBDA/CFBE3
write its original native input geometry, CFC4C/CFC64 write dimensions, and
CFCB0..CFCE1 write only the original NOTEXTSPOT/TEXTSPOT literal sentinel in
row.label. CFCE5 increments the native row count. It never copies its borrowed
full display label into the row, and never writes the annotation at row+64.
Thus translated button input cannot replace the game's internal English
row.label. Its ordinary full constructor still receives the canonical prepared
source and owns painting/layout, while internal marker/action bytes stay native.

Both ordinary CFAF0 After and locale paint_action now commit that same owned
ActionButton TextSource into its real InputOwner's independent row binding.
The actual record is input.row_id in duplicate-row mode, or found by the real
action field at row+C8 in unique-action mode. The annotation is decoded from
that same native row+64. commit_row does not write native model bytes, selection,
geometry or frozen Menu snapshot source bindings. This closes the CF990 commit
bypass for selector measurement and Flow row-source migration without encoding
display strings back into an original-language source.
