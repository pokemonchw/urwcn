## 修订后的规则

1. 依据反编译确认的模块基址、UI 对象和字段，在组件读取、格式化或消费文本的边界按组件语义提供中文。
2. 原生 UI 决定布局、控件、输入、裁剪及缓存生命周期；Mod 在已确认的组件文字绘制调用内按真实目标密度即时绘制高清字形。
3. 禁止全局像素扫描、差分、逐像素跟踪及像素/文字/位置贡献序列；禁止在 RenderCopy、上传或 Present 时遍历旧记录重建画面。
4. 字体自身度量与光栅缓存不保存 UI 位置或页面内容；不以保护、回退、断言或猜测接口补全未确认链路，也不把 1 倍文字放大称为高清。

这些限制已直接写入 AGENTS.md 和现行设计正文。修改前原件保存在回收目录，没有覆盖或删除历史材料。

本次只修改文档，没有修改业务源码、编译、发布 DLL、启动游戏或运行测试。当前正式版卡顿及违规渲染机制仍待代码整改。
