## 原生宽度、分词与按钮

中文经现有 Layout 双字节传输编码；`creation_words()` 仅为原生 `162300` 分词器提供完整字符词元，原5000个130字节槽和 `10EB40` 决定换行与行距。`10EEDA` 原 `MOV AX,[18C8C0]; MOV [EDI],AX` 会在中文字词元后添加可见西文空格；当当前原词元包含已登记传输字符时跳过这一份空格复制，原字符串已有 NUL 不变。该处理属于原生分词空格接口，不保存行槽或排版结果。

`CFAF0` 在 `CFB95 → 114680` 绘制完整借入标签，原生仍持有按钮表、动作及矩形。`CFC40` 的局部前缀宽度和既有 `CFC5D` 的完整标签宽度使用真实完整字符度量；原 `CFC84/CFC8B` 对 `<...>` 的16单位标记扣除继续运行。点号前的键帽仍是原 ASCII，点号后由 `1149F9` 完整串绘字。无点号的 Y/N 标签在 `1146DD` 使用真实字宽生成原按钮背景，`1148E9` 后补全单个双字节字符，`11498A` 由原生字符循环推进；`<`、`>` 标记按原分支不推进文字位置。`11492D`、`114956`、`1149D2` 仍执行原高亮和颜色绘字顺序。
