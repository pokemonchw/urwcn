日期：2026-10-19。目标及 SHA-256 同 [Windows 中文姓名输入记录](20261019-windows-chinese-input.md)。源码为 `modules/adapter/windows_renderer_text.inc`，只接已确认的原生文本/度量边界，不保存页面文本、位置、原生帧或绘制贡献，不创建 UI 布局/缓存，不扫描像素。

renderer 段落的实际 renderer 来自原 `EBP-C30`，描边位来自原flags；面板和按钮同样从各自原局部借入 renderer。度量调用 `render::op::measure_renderer`，所以使用当次原目标和实际输出密度，而不是用主软件面的密度推测另一个目标。所有局部读取都发生在该次原生调用中，没有在Mod状态中保存帧指针。

软件 `CFAF0` 的前缀与完整命中宽度、`114680` 单字符/标记按钮和已有 `10E260 → 10DE90` 五处叶子，由本轮其他独立接线负责；本 include 不重复注册同一地址。

## 主 renderer 另一路文字叶子

`10E3E0` 在保存原 render target、切换到主目标后使用 `10E170`，不是 `10DE90`。其五个确认的调用点为 `10E4BB/10E4D1/10E4E5/10E4F9/10E50E`，完整 CALL 分别为 `E8 B0 FC FF FF`、`E8 9A FC FF FF`、`E8 86 FC FF FF`、`E8 72 FC FF FF`、`E8 5D FC FF FF`。

`10E170` 的真实ABI为 EDX=x，栈参数 y、字符串、打包RGB；它读取原 `image+A2110CC` renderer。原生函数先在自身300字节副本中截去第一个换行符，之后逐字节绘字。新增叶子仅在字符串含已确认显示编码时同步提交完整字形，保持同样的首换行截断、x/y/RGB以及四个原±1描边调用。`10E3E0` 的原目标保存/切换/恢复仍由原代码执行。

这条副本的 UTF-8 编码转换位于姓名 include 的 `10E43D`；纯英文继续原叶子。字体光栅和自身度量缓存不持有UI位置或整页内容，没有延后重放。
