## 原生接入依据与尚未确认部分

已确认菜单数组位于 `image+0x5F4EF10`，行步长 `0xE8`；`0xD0367` 处 ESI 指向当前原生行，EBX 是索引。文本读取与翻译须继续依据该组件及已确认字段。当前菜单绘制经过 `0x10E5A0 → 0x10DDB0`，目标是原生逻辑软件面 `image+0x61BBB10`，随后由原生上传、复制。

`0xCFD10` 是另一种原生纹理菜单构建路径，附带键帽、行字段和动作处理，不是可直接替换主菜单软件绘制的同义函数。`0x113200` 是窗口纹理复制函数；`0x10DF80` 使用 8x10 字形纹理后放大。不能只切标志、放大原文字位图或猜改目标，就声称已得到符合要求的高清链路。

尚未确认主菜单在物理输出密度绘制后，完整接入其原生背景保存、恢复、子窗口与淡变生命周期的改造方式。必须继续建立静态依据；不得以未确认字段、补造路径、保护、回退或断言填补这一缺口。
