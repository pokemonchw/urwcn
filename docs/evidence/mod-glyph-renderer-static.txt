静态接入
========
依据 static-disassembly.txt 的原 font8x10 路径，并只读核对同一 EXE 的
全部 .text 直接 CALL：10DE4D→10BD90，10DF36→10BF20→10BE80，
10E216→10DF80。该结论仅覆盖这四个字形函数的已确认直接调用链，不推断
其他字体、图像、地图绘制或未确认的间接入口。

1. 10DE4D：软件字形由 Render 直接输出到游戏当前 SDL_Surface。
   使用原 ECX/EDX 坐标及原 packed 颜色，按目标像素格式解色；字形 coverage
   混合 RGB 并保留目的像素 alpha，原值为 0 的黑字不会因其 alpha 被丢弃。
2. 10DF36：保留 10BF20 外壳，只保存按值 codepoint/half/width 上下文。
   内部 10BFE0 的 CALL 10BE80 被替代，Mod 向原 scratch surface 的 (0,0)
   输出自己的 8×10 半字形。原清理、ColorKey、建纹理、复制及销毁继续执行。
3. 10E216：保留 10DF80 外壳。10E0C7 的完整六字节
   8D 04 80 C1 E0 04 通过稳定 gateway 接管字形像素段；Mod 向原 renderer
   当时的 8×10 目标绘字后续接 10E12E。原 10DC50 矩形缩放、目标纹理创建、
   清理以及后壳 SetRenderTarget(NULL)/RenderCopy 保留。
   有墨迹的半格保留原 draw blend=0、RGB/alpha255 副作用；空半格保留透明
   清理后的状态。10DC50 是矩形缩放，不是登记脏矩形。

原生 ASCII 0x20–0x7E 也使用 Mod 字体，8×10 单格；已确认原字节映射的
Ä/ä/ö保留单格。中文使用 16×10 双格，每次接入原生 8×10 半格。姓名、
网站、安装路径和原文数据不变，只替换其字体。未确认的原生特殊字节保持
原原生路径，不盲目按 Latin-1 推断。

渲染与热更新
============
Render 仅从自身 RCDATA 字体资源创建 SDL_RWops/TTF_Font，不读取 Windows
字体目录。固定像素字号、统一基线、字形 advance 居中，不按单字墨迹包围盒
裁切后放大；保留原 coverage。缓存键为 (codepoint,width)。软件目标写入与
renderer 纹理输出均在原生当前目标内完成，不调用 Present 或切换目标。
字体、字形表面、临时纹理及 RWops 归 Render 生命周期，在退役时释放。

唯一字体为 Fusion Pixel 12px Monospaced 简中版，固定上游 2026.09.01。
官方来源：https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01
字体及原始 OFL/三个依赖许可证嵌入 RCDATA 101–105；完整来源和 SHA-256
见 assets/fonts/fusion-pixel/SOURCE.md。曾检查的同版 10px 源文件确实缺少
当前词库 U+9E32/U+9E40，故整包改选包含它们的 12px 源，不在运行时回退。
12px cmap 覆盖词库全部可见字符；原 head unitsPerEm=1200，hhea
ascent=1000/descent=-200。Render 固定按 12px 光栅化，再按整字体高度统一
面积采样到 10px；字宽/advance 使用同一比例，保留透明覆盖率，不截掉基线
以下部分。CJK 12→10 墨迹宽居中于原生双格，ASCII 6→5 居中于原生单格。

Adapter 文本状态写入 state 5，兼容已正式发布的 state 3/4。旧 state 4 的
临时字库副本只用于迁移归还，不再用于新绘字。新增六字节 gateway 位于
原进程稳定 replay page+160；保留原 +128 返回桩，登记的短 CALL 仍由驻留
通用 thunk 管理。稳定页不包含可重载 DLL 的函数地址，渲染上下文只保存值。
Host ABI 3、adapter 服务/状态 2/2、驻留桥和启动器不变。
