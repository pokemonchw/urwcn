Method and scope
----------------
This record extracts the complete pictured THANKS AND CREDITS window from
the disk PE, its native callers, token builder, text consumers and key wait.
Ghidra 12.1.4 PUBLIC generated credits-ghidra.c from the existing offline
intro analysis database in read-only mode. credits-extract.ps1 reads PE bytes
and invokes objdump for instruction/string evidence; its -Decompile option
invokes the Ghidra script. These tools do not execute the target executable.
No game launch, injection, live-process interaction, simulated input, product
execution, tests, test cases, assertions or project compilation were used.

This window consists of its title, an introductory paragraph, 21 named/group
acknowledgements, and a press-key button. The implementation presents them in
28 semantic display fields: one title, three introduction rows, 18 individual
acknowledgement rows, three countrymen rows, photo contributors, veteran
players, and the press-key label. This row split derives from the established
text and pictured geometry; it does not add any new acknowledgement content.
Names retain their original spelling. Jarmo Mäenpää uses PE Latin-1 byte E4
for each ä; credits-strings.tsv decodes those bytes explicitly as ISO-8859-1.
